## 3. Responsive Web Design

Website dibuat dengan tampilan **responsive**, sehingga dapat menyesuaikan ukuran layar perangkat.

| Perangkat | Hasil |
|---|---|
| Desktop | ✅ Berjalan dengan baik |
| Mobile | ✅ Berjalan dengan baik |

Dari hasil pengujian, website dapat digunakan dengan baik pada desktop maupun mobile.

---

## 4. Penjelasan Project

**AI Asisten untuk UMKM** adalah website yang dibuat untuk membantu pelaku UMKM mendapatkan informasi dan melakukan konsultasi terkait usaha.

Pada website terdapat halaman informasi mengenai platform dan **Form Konsultasi**. Pengguna dapat mengisi nama pemilik usaha, jenis usaha, dan skala usaha sebelum memulai konsultasi.

Project ini dibuat sebagai **prototype** untuk penerapan AI dalam membantu kebutuhan dan pengembangan usaha UMKM.

---

## 5. Kesimpulan

Website **AI Asisten untuk UMKM** telah berhasil dijalankan pada desktop dan mobile. Tampilan dapat menyesuaikan ukuran layar dan fitur utama seperti informasi platform serta form konsultasi dapat digunakan dengan baik.
